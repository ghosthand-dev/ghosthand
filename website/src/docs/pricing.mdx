ghosthand is **free for one iPhone**, with every core feature and no time limit. **Pro is $99 per month per Mac**, and your agents can use every iPhone plugged into a paid Mac.

You can **[subscribe to Pro](/subscribe)** at any time, before you reach a limit. The link signs you in with Google if needed, then opens Stripe Checkout.

## Plans

|                                           | **Free**              | **Pro**                                   |
| ----------------------------------------- | --------------------- | ----------------------------------------- |
| iPhones                                   | One, on any Mac       | Unlimited on each paid Mac                |
| Time limit                                | None                  | None                                      |
| CLI, MCP server and HTTP API              | ✓                     | ✓                                         |
| Screenshots, OCR, taps, typing, recording | ✓                     | ✓                                         |
| Remote MCP from anywhere                  | ✓                     | ✓                                         |
| Control plane app                         | ✓                     | ✓                                         |
| Phone tasks (`ghosthand task`)            | 10 per month          | Unlimited                                 |
| Daemon source code and private skills     |                       | Read access on GitHub                     |
| Price                                     | **$0**                | **$99 / month per Mac**                   |

Prices are in USD, or the same amount in EUR. A company with 3 Macs full of iPhones pays $297 per month.

## How iPhones and Macs are counted

**Devices bind on their first lease.** ghosthand checks only when an agent takes a lease (`acquire` or `wait`), so it never stops work that is already running.

- **Free.** The first iPhone your agents lease becomes your free iPhone. It works on any Mac. Another iPhone fails with `subscription-required`, and the error names your free iPhone.
- **Pro.** The subscription quantity is the number of paid Macs. The first Macs that lease fill the paid slots, and every iPhone on a paid Mac works. Other Macs can still use the free iPhone.
- **Switching.** The [dashboard](/dashboard) lists the free iPhone and the paid Macs. After you **Remove** one, the next lease binds again.
- **People are never limited.** The control plane preview and Take Control need no lease.

The Mac sends a one-way hash of the iPhone and Mac ids, never the ids themselves, plus their names for the dashboard.

```bash
ghosthand account   # who is signed in, the plan and the subscribe link
```

## Phone tasks

**A phone task is one prompt** to the agent on ghosthand.dev: one `ghosthand task` command, one `task` MCP call or one message in the control plane chat. A follow-up prompt to the same task counts again, because each prompt runs the model.

Free includes **10 phone tasks per calendar month** (UTC). The count resets on the 1st. The 11th task fails with `subscription-required`, and the error has the [subscribe link](/subscribe). Pro has no task limit.

## Offline

When ghosthand.dev cannot be reached, an iPhone that was allowed before **keeps working** for 7 days on Free, and until 3 days after the end of the paid period on Pro. An iPhone that was never checked waits until ghosthand.dev is back.

## Source code

**Pro includes read access to the daemon repository** [ghosthand-dev/ghosthand-daemon](https://github.com/ghosthand-dev/ghosthand-daemon), which has the Swift code and the private skills. The website, the docs and the npm build are open source in [ghosthand-dev/ghosthand](https://github.com/ghosthand-dev/ghosthand).

1. On the [dashboard](/dashboard), type your GitHub username under **Source code**.
2. Accept the invite GitHub emails you. Access is read-only.
3. When the plan ends, access ends too. GitHub removes your forks of the private repo.

The [source license](/docs/source-license) lets you and your team read, change and build the code for your own Macs while you subscribe. It does not let you publish, share or redistribute it, or build a competing product with it.

## Billing

**Billing runs on Stripe.** [Subscribe](/subscribe) from this page or the [dashboard](/dashboard) and pick how many Macs to pay for. After you subscribe, the same button opens the Stripe portal. There you can change the number of Macs or the card, download invoices, or cancel. A canceled plan stays active until the end of the paid month.

ghosthand.dev **never stores** your screenshots, screen text or typed text. They pass through it only for remote MCP calls. Otherwise the Mac sends only the plan check and usage telemetry. See the [privacy policy](./privacy.mdx).
