ghosthand is **free for one iPhone**, with every core feature and no time limit. **Pro is $99 per month per Mac**: your agents can use every iPhone plugged into a paid Mac. [Subscribe from your dashboard](/dashboard).

## Plans

|                                           | **Free**              | **Pro**                                   |
| ----------------------------------------- | --------------------- | ----------------------------------------- |
| iPhones                                   | One, on any Mac       | Unlimited on each paid Mac                |
| Time limit                                | None                  | None                                      |
| CLI, MCP server and HTTP API              | ✓                     | ✓                                         |
| Screenshots, OCR, taps, typing, recording | ✓                     | ✓                                         |
| Remote MCP from anywhere                  | ✓                     | ✓                                         |
| Control plane app                         | ✓                     | ✓                                         |
| Phone tasks (`ghosthand task`)            |                       | ✓                                         |
| Daemon source code and private skills     |                       | Read access on GitHub                     |
| Price                                     | **$0**                | **$99 / month per Mac**                   |

Prices are in USD, or the same amount in EUR. A company with 3 Macs full of iPhones pays $297 per month.

## How iPhones and Macs are counted

**Devices bind on their first lease.** ghosthand checks only when an agent takes a lease (`acquire` or `wait`), so running work is never cut off.

- **Free:** the first iPhone your agents lease becomes your free iPhone. It works on any Mac. Another iPhone fails with `subscription-required`, and the error names your free iPhone.
- **Pro:** the subscription quantity is the number of paid Macs. The first Macs that lease fill the paid slots, and every iPhone on a paid Mac works. Other Macs can still use the free iPhone.
- **Switching:** the [dashboard](/dashboard) lists the free iPhone and the paid Macs. **Remove** one and the next lease binds again.
- **People are never limited.** The control plane preview and Take Control need no lease.

The Mac sends a one-way hash of the iPhone and Mac ids, never the ids themselves, plus their names for the dashboard.

```bash
ghosthand account   # who is signed in, the plan and the subscribe link
```

## Offline

When ghosthand.dev cannot be reached, an iPhone that was allowed before **keeps working**: for 7 days on Free, and until 3 days after the paid period on Pro. An iPhone that was never checked waits until ghosthand.dev is back.

## Source code

**Pro includes read access to the daemon**: the Swift code and the private skills in [ghosthand-dev/ghosthand-daemon](https://github.com/ghosthand-dev/ghosthand-daemon). Everything else, the website, the docs and the npm build, is open source in [ghosthand-dev/ghosthand](https://github.com/ghosthand-dev/ghosthand).

1. On the [dashboard](/dashboard), type your GitHub username under **Source code**.
2. Accept the invite GitHub emails you. Access is read-only.
3. When the plan ends, access ends too. Forks of the private repo are removed by GitHub.

The daemon license lets you read the code and build it for your own Macs while you subscribe. It does not let you redistribute it.

## Billing

**Billing runs on Stripe.** Subscribe from the [dashboard](/dashboard) and pick how many Macs to pay for. After you subscribe, the same button opens the Stripe portal, where you change the number of Macs or the card, download invoices or cancel. A canceled plan stays active until the end of the paid month.

Your screenshots, screen text and typed text **never reach ghosthand.dev**: the Mac sends only the plan check. See the [privacy policy](./privacy.mdx).
