## Before you write

Run these commands on the Mac and paste their output in your email. They do not show secrets.

```bash
ghosthand account   # who is signed in, the plan, when the trial ends
ghosthand list      # the iPhones this Mac sees, and their leases
```

## Common topics

| Topic | Where |
| --- | --- |
| First setup, USB, Trust and Bluetooth pairing | `ghosthand setup`, then the [quick start](/) |
| Plan, invoices, cancel | [Dashboard](/dashboard), then the Stripe portal |
| Sign out a Mac | [Dashboard](/dashboard) or `ghosthand logout` |
| Delete your account and data | Email us, see the [privacy policy](/docs/privacy) |
| Remote MCP server | Add `https://ghosthand.dev/mcp` in your MCP client and sign in with Google |
